You can specify background images
for any visible HTML element.
In this example, the background image
is specified for a div element.
By default, the background-image
will repeat itself in the direction(s)
where it is smaller than the element
where it is specified. Try resizing the
browser window to see how the
background image behaves


Caso queira q a pagina toda tenha a imagem de forma repetida(No CSS):

body{ background-image: url('imgs/img_girl.jpg'); }


E para nao repetir (No CSS)

body { background-image: url('example_img_girl.jpg'); background-repeat: no-repeat; }


Caso queira a Imagem 100% na tela(NO CSS)

body { background-image: url('img_girl.jpg'); background-repeat: no-repeat; background-attachment: fixed; background-size: cover; }

Block e Inline:

Block começa em uma nova linha e ocupa toda a largura (ex.: div, p, h1-h6, ul, table). Inline não quebra a linha e ocupa só o necessário (ex.: span, a, img, strong, em).

Elementos block (div)

Div 1 - ocupa a linha toda
Div 2 - começa em uma nova linha
